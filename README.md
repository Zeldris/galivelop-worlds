# galivelop-worlds
Kit para hacer mundos de ficción vivos con IA local: motor de mundo por turnos, generador de mapas por semilla, RAG
del lore y comprobador de canon. En diseño (ver `docs/handoff.md`).

mezcla con la MIT.
